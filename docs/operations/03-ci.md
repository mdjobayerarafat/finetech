# 3. CI

> 中文: [03-持续集成 (中文)](./zh/03-ci.md)

> **Status:** there is no CI today. The repository has no
> `.github/workflows/` directory. This page is the **recommended
> pipeline** — copy the files into the repo, push, and they
> work.

## 3.1 Goals

The pipeline should answer four questions on every pull request:

1. Does the code **compile** (backend + frontend)?
2. Does it pass **format + lint** (no `cargo fmt` drift, no
   `clippy` warnings, no `next lint` errors)?
3. Do the **unit tests** pass?
4. Does the **smoke script** (`ops/scripts/smoke.sh` from
   [02-test-cases.md](./02-test-cases.md)) still pass against a
   live Postgres?

If yes to all four, merge. The first three are PR gates; the
fourth is a `main`-only gate because it needs a Postgres
service container.

## 3.2 What to **not** gate on

- The LLM is **not** called in CI. Tests that need the LLM are
  the regex stub's responsibility; the LLM is exercised in
  staging.
- Network access to the LLM provider from CI runners is
  unnecessary and a privacy risk.
- `cargo build --release` is **not** a PR gate — debug build is
  enough to catch compile errors. Release is a `main` post-merge
  step that produces the deployable artifact.

## 3.3 GitHub Actions template

`.github/workflows/ci.yml`:

```yaml
name: CI

on:
  pull_request:
  push:
    branches: [main]

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  # --- Backend -------------------------------------------------------------
  backend:
    name: Backend (fmt + clippy + test)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install Rust toolchain
        uses: dtolnay/rust-toolchain@stable
        with:
          components: rustfmt, clippy
      - name: Cache cargo
        uses: Swatinem/rust-cache@v2
      - name: Format check
        working-directory: backendrust
        run: cargo fmt --all -- --check
      - name: Clippy
        working-directory: backendrust
        run: cargo clippy --all-targets -- -D warnings
      - name: Build
        working-directory: backendrust
        run: cargo build --bin bankpilot --bin bankpilot-seed
      - name: Unit tests
        working-directory: backendrust
        run: cargo test --workspace --no-fail-fast

  # --- Frontend ------------------------------------------------------------
  frontend:
    name: Frontend (lint + type-check + build)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm
          cache-dependency-path: frontend/pnpm-lock.yaml
      - name: Install
        working-directory: frontend
        run: pnpm install --frozen-lockfile
      - name: Lint
        working-directory: frontend
        run: pnpm lint
      - name: Type-check + build
        working-directory: frontend
        run: pnpm build

  # --- Smoke (main only) ---------------------------------------------------
  smoke:
    name: API smoke (Postgres)
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    needs: [backend, frontend]
    runs-on: ubuntu-latest
    services:
      postgres:
        image: postgres:16
        env:
          POSTGRES_USER: fintech
          POSTGRES_PASSWORD: fintech
          POSTGRES_DB: bankpilot
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 5s
          --health-timeout 3s
          --health-retries 10
    env:
      DATABASE_URL: postgres://fintech:fintech@localhost:5432/bankpilot
      RUST_LOG: info
    steps:
      - uses: actions/checkout@v4
      - name: Install Rust toolchain
        uses: dtolnay/rust-toolchain@stable
      - name: Cache cargo
        uses: Swatinem/rust-cache@v2
      - name: Build API
        working-directory: backendrust
        run: cargo build --bin bankpilot
      - name: Start API
        working-directory: backendrust
        run: |
          ./target/debug/bankpilot &
          for i in $(seq 1 30); do
            code=$(curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:8080/healthz || echo 000)
            [ "$code" = "200" ] && break
            sleep 1
          done
          test "$code" = "200" || (echo "API never became ready" && exit 1)
      - name: Smoke
        run: bash ops/scripts/smoke.sh
```

## 3.4 What each job catches

| Job | Catches | Skips |
|---|---|---|
| `backend` | `cargo fmt` drift; clippy lints; compile errors; the 39 unit tests in §2.2 | LLM calls; Postgres-dependent paths |
| `frontend` | `next lint` errors; TypeScript errors; bundle-time errors (missing imports, dead code) | Behaviour; visual regressions |
| `smoke` | The end-to-end happy path through login → forecast → redteam → logout | Visual; LLM behaviour; redteam *blocking* on a real injection (we test that the *detector* blocks, not the LLM's response) |

## 3.5 What to add later

When the gaps in [02-test-cases.md §2.6](./02-test-cases.md#26-coverage-gaps-what-we-dont-test) are filled, the CI grows with them:

- **Frontend tests** (`vitest` + `@testing-library/react`):
  add a `frontend-tests` job that runs `pnpm test` and gates
  the PR.
- **End-to-end tests** (Playwright): add an `e2e` job that
  boots the full stack in a `docker compose` workflow and
  exercises the chat + confirmation flow.
- **Load test** (k6/wrk): add a `load` job, weekly schedule
  only, with a Postgres pool sized to handle 100 rps. Report
  p99 latencies; alert on regression > 25%.
- **Accessibility audit** (axe-core): add a Playwright
  integration that runs `axe` on every page.
- **LLM-output regression**: a `llm-regression` job that runs
  the regex stub against a fixed input and snapshots the
  proposal. Catches accidental changes to the stub.
- **Security audit** (`cargo audit` + `pnpm audit`): weekly
  schedule; opens an issue on any new advisory.

## 3.6 Branch protection

Recommended rules on `main`:

- Require **2 reviews** (one from a code owner) for any PR that
  touches `backendrust/src/{policy,fraud,audit,tools,planner}.rs`
  or `frontend/src/lib/api.ts`.
- Require **all checks to pass**: `backend`, `frontend`,
  `smoke` (post-merge).
- **No force-push** to `main`.
- **Linear history** (`Require linear history`); squash-merge
  to keep the log readable.

## 3.7 Local parity

A single command that mirrors what CI does:

```bash
# From the repo root.
set -euo pipefail
cd backendrust
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
cargo test --workspace
cd ../frontend
pnpm install --frozen-lockfile
pnpm lint
pnpm build
echo "OK"
```

`make ci` (if you wire a `Makefile`) is a friendlier alias. The
script above is the **minimum bar** for "the PR is good to go".
