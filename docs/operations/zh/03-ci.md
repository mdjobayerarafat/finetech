# 3. 持续集成

> English: [03-ci.md](../03-ci.md)

> **现状:** 目前没有 CI。仓库中没有 `.github/workflows/`
> 目录。本页是**推荐的流水线** —— 把文件拷进仓库,push,
> 就能跑。

## 3.1 目标

流水线对每个 PR 回答四个问题:

1. 代码能**编译**吗(后端 + 前端)?
2. 能过**格式 + lint** 吗(无 `cargo fmt` drift、无 `clippy`
   warning、无 `next lint` 错误)?
3. **单元测试**通过吗?
4. **smoke 脚本**([02-test-cases.md](./02-test-cases.md) 的
   `ops/scripts/smoke.sh`)对真实 Postgres 还能跑通吗?

四问全 yes,合并。前三个是 PR gate;第四个仅在 `main` 上 gate,
因为它需要 Postgres service container。

## 3.2 **不要** gate 的

- CI 中**不**调 LLM。需要 LLM 的测试由 regex stub 负责;LLM 在
  staging 跑。
- CI runner 不需要、也**不应该**访问 LLM provider(隐私风险)。
- `cargo build --release` **不**是 PR gate —— debug build 足够
  抓编译错。Release 是 `main` 合并后的步骤,产出可部署工件。

## 3.3 GitHub Actions 模板

`.github/workflows/ci.yml`:

```yaml
name: CI

on:
  pull_request:
  push:
    branches: [main]

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  # --- 后端 ---------------------------------------------------------------
  backend:
    name: Backend (fmt + clippy + test)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install Rust toolchain
        uses: dtolnay/rust-toolchain@stable
        with:
          components: rustfmt, clippy
      - name: Cache cargo
        uses: Swatinem/rust-cache@v2
      - name: Format check
        working-directory: backendrust
        run: cargo fmt --all -- --check
      - name: Clippy
        working-directory: backendrust
        run: cargo clippy --all-targets -- -D warnings
      - name: Build
        working-directory: backendrust
        run: cargo build --bin bankpilot --bin bankpilot-seed
      - name: Unit tests
        working-directory: backendrust
        run: cargo test --workspace --no-fail-fast

  # --- 前端 ---------------------------------------------------------------
  frontend:
    name: Frontend (lint + type-check + build)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm
          cache-dependency-path: frontend/pnpm-lock.yaml
      - name: Install
        working-directory: frontend
        run: pnpm install --frozen-lockfile
      - name: Lint
        working-directory: frontend
        run: pnpm lint
      - name: Type-check + build
        working-directory: frontend
        run: pnpm build

  # --- Smoke (仅 main) ----------------------------------------------------
  smoke:
    name: API smoke (Postgres)
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    needs: [backend, frontend]
    runs-on: ubuntu-latest
    services:
      postgres:
        image: postgres:16
        env:
          POSTGRES_USER: fintech
          POSTGRES_PASSWORD: fintech
          POSTGRES_DB: bankpilot
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 5s
          --health-timeout 3s
          --health-retries 10
    env:
      DATABASE_URL: postgres://fintech:fintech@localhost:5432/bankpilot
      RUST_LOG: info
    steps:
      - uses: actions/checkout@v4
      - name: Install Rust toolchain
        uses: dtolnay/rust-toolchain@stable
      - name: Cache cargo
        uses: Swatinem/rust-cache@v2
      - name: Build API
        working-directory: backendrust
        run: cargo build --bin bankpilot
      - name: Start API
        working-directory: backendrust
        run: |
          ./target/debug/bankpilot &
          for i in $(seq 1 30); do
            code=$(curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:8080/healthz || echo 000)
            [ "$code" = "200" ] && break
            sleep 1
          done
          test "$code" = "200" || (echo "API never became ready" && exit 1)
      - name: Smoke
        run: bash ops/scripts/smoke.sh
```

## 3.4 各 job 抓什么

| Job | 抓到 | 跳过 |
|---|---|---|
| `backend` | `cargo fmt` drift;clippy lint;编译错;§2.2 中 39 条单元测试 | LLM 调用;依赖 Postgres 的路径 |
| `frontend` | `next lint` 错;TypeScript 错;打包期错(缺 import、dead code) | 行为;视觉回归 |
| `smoke` | login → forecast → redteam → logout 的端到端 happy path | 视觉;LLM 行为;真实注入下 *block*(我们测的是*检测器*会 block,不是 LLM 怎么回) |

## 3.5 后续要加的

[02-test-cases.md §2.6](./02-test-cases.md#26-覆盖缺口没测的) 里的缺口补上时,CI 跟着加:

- **前端测试**(`vitest` + `@testing-library/react`):加一个
  `frontend-tests` job,跑 `pnpm test`,gate PR。
- **E2E 测试**(Playwright):加 `e2e` job,在 `docker compose`
  里起整套栈,跑 chat + confirm 流程。
- **压测**(k6/wrk):加 `load` job,仅周跑,Postgres 池要能
  撑 100 rps。报 p99 延迟;回退 > 25% 告警。
- **可访问性审计**(axe-core):Playwright 集成,对每页跑
  `axe`。
- **LLM 输出回归**:`llm-regression` job,对固定输入跑 regex
  stub,快照 proposal。抓 stub 的意外变更。
- **安全审计**(`cargo audit` + `pnpm audit`):周跑;有新
  公告就开 issue。

## 3.6 分支保护

`main` 的推荐规则:

- 任何触碰 `backendrust/src/{policy,fraud,audit,tools,planner}.rs`
  或 `frontend/src/lib/api.ts` 的 PR 需 **2 个 review**(其中一
  个 code owner)。
- 需 **所有检查通过**:`backend`、`frontend`、`smoke`(合并
  后)。
- **不允许**强推到 `main`。
- **线性历史**(`Require linear history`);squash-merge 保持
  日志可读。

## 3.7 本地对等

一个命令镜像 CI:

```bash
# 从仓库根。
set -euo pipefail
cd backendrust
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
cargo test --workspace
cd ../frontend
pnpm install --frozen-lockfile
pnpm lint
pnpm build
echo "OK"
```

`make ci`(若接了 `Makefile`)是更友好的别名。上面这段是
"PR 可以合并"的**最低线**。
