# 5. 我们未声称的事

> English: [05-non-claims.md (EN)](../05-non-claims.md)

- 我们**没有**声称本平台已可用于生产。[§4](./04-known-risks.md)
  中每一项都必须在它承载真金白银之前关闭。
- 我们**没有**声称大模型是安全的。红队套件是回归网,
  不是证明。
- 我们**没有**声称审计日志在密码学意义上是不可篡改的。
  [R-2](./04-known-risks.md#r-2) 与
  [R-12](./04-known-risks.md#r-12)
  写明了差距。
- 我们**没有**声称跨场景编排是新颖的——它就是规划器 +
  工具白名单 + 储蓄目标 + 提醒的组合。新颖之处在于集成:
  让转账在 MFA 处暂停的同一套管道,让生日预留也在 MFA
  处暂停。
